Northstar Console is a full-stack operations dashboard built with Next.js and designed to grow into a production-ready internal tool.

## Documentation

- [Project Guide](./PROJECT_GUIDE.md)
- [Roadmap](./ROADMAP.md)

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The app source lives in `src/`. The initial scaffold is in place and ready for the next phase:

- Ant Design app shell and theme system
- Prisma + Postgres data layer
- Simple credentials auth
- Core dashboard modules and deploy setup

## Stack

- Next.js 16
- React 19
- TypeScript
- Turbopack
- Vercel deployment target
