Northstar Console is a Next.js project scaffold prepared for a full-stack internal operations dashboard.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The app source lives in `src/`.

## Stack

- Next.js 16
- React 19
- TypeScript
- Ant Design
- Prisma
- NextAuth
- TanStack Query
- Vercel deployment target
